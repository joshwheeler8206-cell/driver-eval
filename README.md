# U.S. AutoForce Quarterly Driver Evaluation
Mobile PWA for ride-along assessments. Open via GitHub Pages and install to home screen.

## Install
- **Live site:** https://joshwheeler8206-cell.github.io/driver-eval/
- **Android APK:** [driver-eval.apk](https://github.com/joshwheeler8206-cell/driver-eval/releases/download/v1.0.0/driver-eval.apk) (signed, standalone app)
- **iPhone / iPad:** open the live site in Safari, tap **Share** → **Add to Home Screen** (fullscreen PWA; use Safari for the print/PDF buttons)
